# Jump Start

A custom starter kit for Laravel development, with defaults I like.

[![MIT Licensed](https://img.shields.io/badge/License-MIT-blue.svg?style=flat-square)](LICENSE.md)

## Installation

```bash
laravel new <my-app> --using=awcodes/jump-start
```

## Includes

- Laravel 13
- Tailwind CSS
- Pint
- Pest
- Rector
- Laravel Debugbar
- Spatie Ray
- Larastan
- Laravel Boost
